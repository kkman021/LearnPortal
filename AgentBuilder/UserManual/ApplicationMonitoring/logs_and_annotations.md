> Ensure your application complies with local regulations when collecting user data. Publishing a privacy policy and obtaining user consent is recommended.

The logging feature in AgentBuilder records all interaction processes, whether accessed via WebApp or API. This provides prompt engineers and LLM administrators with a visual operational experience.

---

## Using the Logs Console
- Click **Logs and Ann.** in the left navigation.
- The page displays:
  - User interaction records for the selected time period.
  - User input and AI output (as message flows in conversational apps).
  - User/admin evaluations and improvement annotations.
- **Note:** If multiple team members annotate the same log, the last annotation overwrites previous ones.

## Improve Annotations
- ![Log Annotation](https://docs.wise-paas.advantech.com/dataSource/resource/1723623422110738850.png)
- Click a log to open the details panel, where admins can:
  - Give a thumbs up for good messages.
  - Give a thumbs down for poor messages.
  - Mark improved responses (the text you expect AI to reply with).
- **Note:** The last annotation by any admin will override previous ones.

## Enabling Annotated Replies in Logs and Annotations
- Enable the annotation reply switch on the Annotations page under Logs & Ann. in the left menu.
- ![Enable Annotation Reply](https://docs.wise-paas.advantech.com/dataSource/resource/1723623431621583619.png)
