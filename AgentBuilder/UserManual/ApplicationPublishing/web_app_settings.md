Web applications are designed for end users. When you create an application in AgentBuilder, a corresponding web app is generated. Users can access the web app without logging in, and it is responsive for PC, tablet, and mobile devices.

---

## Web App Content and Updates
- The web app content matches the published application's configuration.
- When you modify the app's configuration and click **Publish** on the prompt orchestration page, the web app updates to reflect the latest settings.

## Managing Web App Site Information
- On the application overview page, you can enable/disable web app access and edit site information, including:
  - Icon
  - Name
  - Description
  - Interface language
  - Copyright
  - Privacy policy link

## Feature Availability
- The web app's features and performance depend on what is enabled during orchestration, such as:
  - Conversation opening remarks
  - Variables to fill before conversation
  - Next step suggestions
  - Speech-to-text
  - References and attributions
  - More similar answers (for text-based apps)
