A text generator application automatically creates high-quality text based on user prompts. It can generate summaries, translations, and more.

---

## Supported Features
- Run once
- Run in batches
- Save run results
- Generate more similar results

---

## Run It Once
- Enter your query and click **Execute**. The result appears on the right.
![Run Once](https://docs.wise-paas.advantech.com/dataSource/resource/1727343901091547804.png)
- In the results section, click **Copy** to copy content or **Save** to store it. Saved content appears in the **Saved** tab. You can also like/dislike generated content.

## Run in Batches
- For large tasks (e.g., generating 100 articles on different topics), use batch operation:
  - Go to the **Run Batch** tab.
  ![Run Batch Tab](https://docs.wise-paas.advantech.com/dataSource/resource/1727343922311597383.png)
  - Download the template, fill in your data, save as `.csv`, and upload it back to AgentBuilder.
