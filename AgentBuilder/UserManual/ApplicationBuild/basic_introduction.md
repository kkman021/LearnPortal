In AgentBuilder, an *application* is a practical scenario solution built on large language models (such as GPT). By creating applications, you can leverage intelligent AI technology to address specific requirements.

**Key features delivered to developers:**

- Encapsulated, user-friendly LLM API for backend or frontend use, authenticated via Token.
- Out-of-the-box, visually appealing, and hosted Web App, customizable for further development.
- A suite with prompt engineering, context management, log analysis, and annotation, all with a user-friendly interface.

*You can choose any or all of these features to support your AI application development.*
