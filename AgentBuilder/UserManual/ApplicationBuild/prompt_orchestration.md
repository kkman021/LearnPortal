AgentBuilder provides an intuitive keyword orchestration interface, allowing you to visually compose application features based on keywords. Well-chosen keywords can improve model output quality, reduce errors, and meet specific scenario requirements.

---

## Using Prompt Orchestration
- Go to the Orchestrate page of your application.
- Find the input box for prompt orchestration.
