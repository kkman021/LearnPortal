You can create applications in AgentBuilder Studio in several ways:

- **From a Template**
  - Recommended for beginners.
  - Go to the home page and select **Studio > CREATE APP > Create from Template**.
  - ![Create from Template](https://docs.wise-paas.advantech.com/dataSource/resource/1723619363411158488.png)
  - ![Template List](https://docs.wise-paas.advantech.com/dataSource/resource/1723619342430863378.png)
  - Choose a template (e.g., "Classifier Knowledge + Chatbot"), update the icon and name if needed, add a description, and click **Create** to start editing your application.
  - ![Template Example](https://docs.wise-paas.advantech.com/dataSource/resource/1723619488852760480.png)

- **From Blank**
  - Go to **Studio > CREATE APP > Create from Blank**.
  - ![Create from Blank](https://docs.wise-paas.advantech.com/dataSource/resource/1723619315449169313.png)
  - Before starting, review the four application types: Chatbot, Text Generator, Agent, and Workflow.

- **From a DSL File (Local/Online)**
  - Import an application configuration using a DSL file.
