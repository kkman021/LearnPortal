- Go to the homepage, click **Knowledge > Create Knowledge** go to the Knowledge page.

- Import from file: Currently supported file formats include TXT, MARKDOWN, PDF, HTML, XLSX, XLS, DOCX, CSV, EML, MSG, PPTX, PPT, XML, EPUB, PPT, HTM with each file not exceeding 15 MB. You can upload files by dragging and dropping or selecting them.

- After dragging the file, click “next” Here we use the example document “Workday FAQ”.

![Image 7: knowledge-1.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723614406048003078.png)

- Enter Text Processing and Cleaning page, as shown in the figure below:

![Image 8: knowledge-22.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723614633811065026.png)

**Chunk settings:** Optional automatic segmenting and cleaning, or you can customize it. Preview the segmentation on the right side in real time.

**Note:** Here we use custom segmentation. As shown in the example, we use the # segment identifier to improve the readability of the text.

![Image 9: knowledge-2.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723614415887670595.png)

- Adjust the segments and save, you can view the uploaded knowledge base in the document.

![Image 10: knowledge-4.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723614506356768257.png)

- You can click on a segment to view and edit it. If you are not satisfied with the segment, you can manually modify the content here.

![Image 11: knowledge-4.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723614506356768257.png)
