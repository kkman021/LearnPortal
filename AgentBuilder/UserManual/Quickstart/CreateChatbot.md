Below is an example of a **Workday FAQ** application.

- Click **Studio > CREATE APP > Create from Blank** to create an application. Fill in the application name, select the application type as Chatbot, select the orchestrate method as Basic, and click “Create” to create the application.

![Image 1: quick-1.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723615669841922739.png)

- The application will automatically navigate to the Orchestrate page after successful creation.

![Image 2: Create Chatbot-1.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1732697262584273078.png)

- Please fill in the prompts. The prompts we fill in here are:

```
You are an Workday Q&A assistant, please use the context content as your learning knowledge, and answer based on the language of the user's questions.
```

![Image 3: quick-3.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723615682458903741.png)

- Click the Add button in the Context and select the Workday FAQ added in the previous chapter.

![Image 4: Create Chatbot-2.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1732697287380633000.png)

- Click the “Manage” button below to open the “Conversation Opener” and add the conversation opener:

![Image 5: Create Chatbot-3.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1732697299097307574.png)

![Image 6: Create Chatbot-4.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1732697311329206697.png)

- Choose the model:

![Image 7: quick-7.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723615724834651340.png)
