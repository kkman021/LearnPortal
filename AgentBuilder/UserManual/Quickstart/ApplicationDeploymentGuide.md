## Application Deployment Guide

Once you have finished debugging the application, you can proceed to deploy it as follows:

- Click the **Publish** button at the top right corner of the interface, then click **Update** to save as the latest version.

  ![chatbot-3.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1725355595918774178.png)

- Click **Publish > Run App** to enter the application interface, or click **Monitoring > Preview** to enter the application interface.

  ![quick-10.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723615936164276737.png)

  ![quick-11.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723615943218455350.png)

- The application has been created. You can now start using it!
