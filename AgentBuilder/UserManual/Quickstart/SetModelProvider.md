1.   Click **Settings > Model Provider > Add Model**.

![Image 5: model-provider-1.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723606627098735672.png)

2.   Please fill in the model information and click “Save” to submit. If all information is correct, the model can be successfully added.

![Image 6: model-provider-2.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723606675607847050.png)

3.   Click on “System Model Settings” in the upper right corner to set the default model to use.

![Image 7: model-provider-3.PNG](https://docs.wise-paas.advantech.com/dataSource/resource/1723606640706536323.png)
