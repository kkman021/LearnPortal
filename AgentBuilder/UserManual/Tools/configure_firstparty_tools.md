AgentBuilder provides a range of built-in (first-party) tools to enhance your AI applications. These tools include search, image generation, data scraping, and more.

---

## Supported First-Party Tools

| Tool                | Description                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| GoogleSearch        | Perform Google searches and extract snippets/web pages.                      |
| WikipediaSearch     | Search Wikipedia and extract snippets/web pages.                             |
| DALL-E              | Generate high-quality images from natural language input.                    |
| WebScraper          | Scrape web data.                                                            |
| WolframAlpha        | Perform advanced mathematical computations and get standardized answers.     |
| ChartGenerator      | Generate visual charts (bar, line, pie, etc.).                              |
| CurrentTime         | Query the current time.                                                     |
| YahooFinance        | Get and organize the latest financial news and stock quotes.                 |
| Stable Diffusion    | Generate images locally using stable-diffusion-webui.                       |
| Vectorizer.AI       | Convert PNG/JPG images to SVG vector graphics.                              |
| YouTube             | Retrieve statistics for YouTube channel videos.                              |

---

## How to Configure First-Party Tools

- Go to the tool configuration page in AgentBuilder.
- Enter the required credentials for each tool.
- After successful verification, the tool will show an "Authorized" status.
- Once configured, all workspace members can use the tool in their applications.
