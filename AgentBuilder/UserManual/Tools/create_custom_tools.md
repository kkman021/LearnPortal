AgentBuilder allows you to import custom API tools, supporting OpenAPI/Swagger and ChatGPT Plugin specifications. This enables you to extend your AI application's capabilities with your own APIs.

---

## How to Import a Custom Tool

- Go to **Tools > Custom** in AgentBuilder.
- Paste the OpenAPI schema content or import it from a URL.
- Choose the authentication method (None or API Key).

![Import Custom Tool](https://docs.wise-paas.advantech.com/dataSource/resource/1723627499246920541.png)

---

## Tool Parameter Preview and Testing

- After importing the schema, AgentBuilder will automatically parse and preview the tool's parameters, methods, and paths.
- You can test tool parameters directly in the interface.

![Tool Parameter Preview](https://docs.wise-paas.advantech.com/dataSource/resource/1723627512058016811.png)

---

## Using Custom Tools

- Once created, all workspace members can use the custom tool when building applications in the Studio.
