AgentBuilder knowledge bases support importing data from external tools such as Jina Reader, Firecrawl, and KB Insight. Complete the configuration before importing data.

---

## Authorization Verification

- Go to **Settings > Data Source > Add a data source > Configure** to complete authorization.

![Data Source Authorization](https://docs.wise-paas.advantech.com/dataSource/resource/1742438029257169358.png)

---

## Importing Data

- After authorization, go to the knowledge base creation page.
- Click **Sync from website** or **Sync from KB Insight** and select the required provider to import data.
