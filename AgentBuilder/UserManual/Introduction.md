## What is AgentBuilder?

IoTSuite/AgentBuilder is a platform that builds AI native applications based on large language models. Developers can quickly and easily create high-quality intelligent entities through tools, knowledge bases, workflows, and other methods, reducing the development threshold of AI native applications and helping developers quickly build production-level generative AI applications. Even non-technical personnel can quickly participate in the production and data operation process of AI applications.

AgentBuilder has built-in key technology stack for constructing large language models applications, including support for hundreds of models, an intuitive prompt word arrangement interface, a high-quality RAG engine, and a flexible Agent framework, while also providing an easy-to-use interface and API. This saves developers a lot of time in reinventing the wheel and allows them to focus more on innovation and business needs.

## Why Use AgentBuilder?

AgentBuilder provides a complete solution to help users develop AI applications quickly and efficiently. Its product advantages are as follows:
- **Rich model library:** Supporting various mainstream models, covering multiple fields such as natural language processing, image recognition, speech synthesis, etc., allowing for free switching and smooth migration.
- **Efficient data integration:** The knowledge base management function allows developers to integrate external data in a simple way and automatically integrate it into AI applications, improving the efficiency of knowledge base construction.
- **Zero code application development:** Provides a visual orchestration tool, allowing developers to easily create and deploy AI applications with simple configuration, without the need for complex coding processes.
- **Powerful LLMOps capability:** Provides enterprise-level LLMOps functionality, allowing for monitoring of inference process, logging, data labeling, and more, to better manage and optimize AI applications.
- **Out-of-the-box template applications:** Offering a wide range of pre-built application templates, especially in the industrial sector, combined with Advantech's Industrial IoT platform products, empowering users' business deeply.
- **Flexible scalability:** The platform offers a simple API extension method, allowing developers to easily integrate external tools and expand the capabilities of LLM.
