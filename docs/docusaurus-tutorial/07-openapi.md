## 建立一個新的 Docs 資料庫

這邊以建立一個新的 docs 資料庫來做範例，建立方式可以參考「建立多個 Docs 資料庫」這篇文章

建立一個名為 `openApi` 的 docs 資料庫，並在 openApi 資料夾下新增 `member` 和 `product` 這兩個資料夾

```markdown
website
├── openApi              # openApi 資料庫 
│   ├── member           # member 資料夾
│   └── product          # product 資料夾
├── sidebarsOpenApi.js   # openApi 資料庫的 sidebars.js
├── docusaurus.config.js
└── package.json
```

```jsx
/* sidebarsOpenApi.js */

const sidebars = {
  openApiSidebars: [{ type: 'autogenerated', dirName: '.' }],
};

export default sidebars;
```

調整設定檔

```jsx
/* docusaurus.config.js */

const config = {
  plugins: [
    [
      '@docusaurus/plugin-content-docs',
      {
        id: 'openApi',
        path: 'openApi',
        routeBasePath: 'openApi',
        sidebarPath: require.resolve('./sidebarsOpenApi.js'),
        docItemComponent: "@theme/ApiItem" // 使用 theme-openapi-docs 的樣式
      },
    ],
  ],
  themeConfig: ({
    navbar: {
      items: [
        {
          to: '/openApi',
          position: 'left',
          label: 'openApi',
          activeBaseRegex: `/openApi/`,
        },
      ]
    }
  })
}
```

## 安裝 Docusaurus OpenApi Docs

安裝套件與樣式

```bash
# 安裝 docusaurus-openapi-docs
npm i docusaurus-plugin-openapi-docs

# 安裝 docusaurus-openapi-docs 樣式
npm i docusaurus-theme-openapi-docs
```

Docusaurus OpenAPI Docs 使用的方式是將 API 來源的 yaml 檔整合進特定位置的資料夾內，這邊需要在設定檔調整指定的 input 與 output

```jsx
/* docusaurus.config.js */

const config = {
  plugins: [
    [
      'docusaurus-plugin-openapi-docs',
      {
        id: "api", // plugin id
        docsPluginId: "classic",
        config: {
          member: {
            specPath: "src/api/member.yml",  // Member API 的 yaml 檔
            outputDir: "openApi/member",     // Member API 要顯示的路徑（前面新增的 openApi/member 資料夾）
            sidebarOptions: {
              groupPathsBy: "tag",
            },
          },
          product: {
            specPath: "src/api/product.yml", // Product API 的 yaml 檔
            outputDir: "openApi/product",    // Product API 要顯示的路徑（前面新增的 openApi/product 資料夾）
            sidebarOptions: {
              groupPathsBy: "tag",
            },
          },
        }
      },
    ]
  ],
  
  themes: [
    'docusaurus-theme-openapi-docs', // 引入樣式套件
  ]
}
```

## 新增 API 的 YAML 檔

API 的 yaml 檔我是放在 src/api 資料夾裡面，要放在任何位置都可以，但要記得修改 docusaurus.config.js 的設定

```markdown
website
└── src
    └── api
        ├── member.yml  # Member API 的 yaml 檔
        └── product.yml # Product API 的 yaml 檔
```

```yaml
# member.yml

openapi: 3.0.1
info:
  title: User Management API
  description: API for managing users in the system.
  version: 1.0.0
servers:
  - url: https://api.example.com/v1
    description: Production Server
paths:
  /users:
    get:
      summary: Get all users
      description: Retrieve a list of all users.
      responses:
        '200':
          description: Successful response
          content:
            application/json:
              schema:
                type: array
                items:
                  $ref: '#/components/schemas/User'
    post:
      summary: Create a user
      description: Add a new user to the system.
      requestBody:
        required: true
        content:
          application/json:
            schema:
              $ref: '#/components/schemas/User'
      responses:
        '201':
          description: User created successfully
  /users/{id}:
    get:
      summary: Get user by ID
      description: Retrieve a specific user by their ID.
      parameters:
        - name: id
          in: path
          required: true
          description: ID of the user
          schema:
            type: string
      responses:
        '200':
          description: User retrieved successfully
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/User'
        '404':
          description: User not found
components:
  schemas:
    User:
      type: object
      properties:
        id:
          type: string
          example: 12345
        name:
          type: string
          example: John Doe
        email:
          type: string
          example: johndoe@example.com
```

## 輸出 API 文檔

接著在終端機輸入指令，將指定的 yaml 檔轉換成 mdx 格式，並輸出到對應的資料夾

```bash
# 將 yaml 轉成 mdx 格式，並輸出到對應的資料夾
npm run docusaurus gen-api-docs all
```

接著在指定的資料夾就會出現對應的 mdx 檔案了

```markdown
website
├── openApi
│   ├── member
│   │   └ create-a-user.api.mdx     # Member API 的 mdx 檔
│   └── product
│       └ add-a-new-product.api.mdx # Product API 的 mdx 檔
├── docusaurus.config.js
└── package.json
```

:::info
每次修改 yaml 檔後，都需要記得重新輸出一次
:::

### 動態設定 API 文檔

由於每次新增 yaml 檔後，都需要在設定檔設定欄位，這樣很麻煩，所以我們可以把他寫成一個 Plugin，動態配置這些設定

```jsx
import path from "path";
import fs from "fs";

const generateOpenApiPlugins = () => {
  const openapiDir = path.resolve(__dirname, 'src/api'); // yaml 檔放置的資料夾
  const openapiFiles = fs.readdirSync(openapiDir).filter(file => file.endsWith('.yml')); // 找到所有的 yaml 檔

  const config = openapiFiles.reduce((data, file) => {
    const id = path.basename(file, '.yml');
    data[id] = {
      specPath: path.join(openapiDir, file),
      outputDir: `openApi/${id}`, // API 文檔輸出的位置
      sidebarOptions: {
        groupPathsBy: 'tag',
      }
    }
    return data;
  }, {});

  const result = [
    'docusaurus-plugin-openapi-docs',
    {
      id: 'api', // plugin id
      docsPluginId: 'classic',
      config,
    },
  ];
  return result;
};

// 將原本的設定移除，直接使用 Plugin 就可以了

const config = {
  plugins: [
    generateOpenApiPlugins(),

}
```
