# 建立多個 Docs 資料庫

這邊以新增 demo、tutorial 這兩個 Docs 資料庫為例：

首先先在專案中新增資料庫資料夾（demo、tutorial），以及對應的 sidebars.js（sidebarsDemo.js、sidebarsTutorial.js）

```markdown
website
├── demo                 # demo 資料庫 
│   ├── foo
│   │   └── bar.md
│   └── hello.md
├── tutorial             # tutorial 資料庫      
│   ├── foo
│   │   └── bar.md
│   └── hello.md
├── sidebarsDemo.js      # demo 資料庫的 sidebars.js
├── sidebarsTutorial.js  # demo 資料庫的 sidebars.js
├── docusaurus.config.js
└── package.json
```

調整 sidebars.js，`autogenerated` 的意思是指根據資料夾結構自動生成 sidebar

```jsx
/* sidebarsDemo.js */

const sidebars = {
  demoSidebars: [{ type: 'autogenerated', dirName: '.' }],
};

export default sidebars;
```

```jsx
/* sidebarsTutorial.js */

const sidebars = {
  tutorialSidebars: [{ type: 'autogenerated', dirName: '.' }],
};

export default sidebars;
```

調整設定檔，在 plugins 添加設定檔集、在 navbar 添加 Header 選單

```jsx
/* docusaurus.config.js */

const config = {
  plugins: [
    [
      '@docusaurus/plugin-content-docs',
      {
        id: 'demo',
        path: 'demo',
        routeBasePath: 'demo',
        sidebarPath: require.resolve('./sidebarsDemo.js'),
        // includeCurrentVersion: false
      },
    ],
    [
      '@docusaurus/plugin-content-docs',
      {
        id: 'tutorial',
        path: 'tutorial',
        routeBasePath: 'tutorial',
        sidebarPath: require.resolve('./sidebarsTutorial.js'),
        // includeCurrentVersion: false
      },
    ],
  ],
  
  themeConfig: ({
    navbar: {
      items: [
        {
          to: '/demo/intro',
          position: 'left',
          label: 'Demo',
          activeBaseRegex: `/demo/`,
        },
        {
          to: '/tutorial/intro',
          position: 'left',
          label: 'Tutorial',
          activeBaseRegex: `/tutorial/`,
        },
      ]
    }
  })
}
```
