# 多語系管理

在設定檔設定多語系（en、zh-tw）

```jsx
/* docusaurus.config.js */

const config = {
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'zh-tw'],
    localeConfigs: {
      en: {
        htmlLang: 'en',
      },
      'zh-tw': {
        htmlLang: 'zh-tw',
      },
    },
  },
}
```

在 navbar 添加語系選擇的下拉選單

```jsx
/* docusaurus.config.js */

const config = {
  themeConfig: ({
    navbar: {
      items: [
        {
          type: 'localeDropdown',
          position: 'right',
        },
      ]
    }
  })
}
```

1. 在根目錄新增 i18n/zh-tw 資料夾
2. 根據 Docs 名稱新增對應的資料夾，規則為 `docusaurus-plugin-content-docs-{id}` （如 demo 資料庫就是 `docusaurus-plugin-content-docs-demo`）
3. 在 `docusaurus-plugin-content-docs-demo` 底下新增 current 資料夾
4. 第一次新增多語系檔案需要手動搬移，這邊將 demo 裡面的檔案複製到 i18n/zh-tw/docusaurus-plugin-content-docs-demo/current 裡面，並針對內容去做文案編輯

```markdown
website
├── demo                                            # demo 資料庫 
│   ├── foo
│   │   └── bar.md
│   └── hello.md
└── i18n
    └── zh-tw
        ├── docusaurus-plugin-content-docs-demo     # demo 資料庫的多語系版本
        │   └── current                             # demo 資料庫 zh-tw 版本的檔案
        │       ├── foo
        │       │   └── bar.md
        │       └── hello.md 
        └── docusaurus-plugin-content-docs-tutorial # tutorial 資料庫的多語系版本
            └── current                             # tutorial 資料庫 zh-tw 版本的檔案
                ├── foo
                │   └── bar.md
                └── hello.md 
```

設定 i18n 後，未來若有輸出版本時也會一併產出多語系檔案

```bash
# 例如建立 2.0.0 的 demo 資料庫
npm run docusaurus docs:version:demo 2.0.0
```

輸出版本時會一併在 docusaurus-plugin-content-docs-demo 內生成 version 資料夾

```markdown
# 在 docusaurus-plugin-content-docs-demo 資料夾內會自動產生 version-2.0.0 的檔案

website
└── i18n
    └── zh-tw
        ├── docusaurus-plugin-content-docs-demo     # demo 資料庫的多語系版本
        │   ├── current                             # demo 資料庫 zh-tw 版本的檔案
        │   ├── version-2.0.0                       # demo 資料庫 zh-tw 版本的檔案（2.0.0）
        │   └── version-1.0.0                       # demo 資料庫 zh-tw 版本的檔案（1.0.0）
        └── docusaurus-plugin-content-docs-tutorial # tutorial 資料庫的多語系版本
            ├── current                             # tutorial 資料庫 zh-tw 版本的檔案
            ├── version-2.0.0                       # tutorial 資料庫 zh-tw 版本的檔案（2.0.0）
            └── version-1.0.0                       # tutorial 資料庫 zh-tw 版本的檔案（1.0.0）
```

## Run Start

Docusaurus 不允許在本地一次運行多種語系版本，只能針對特定語系 run start

```bash
# 在本地運行 zh-tw 版本的網頁
npm run start -- --locale zh-tw
```

## 產生翻譯檔

以上為設定多語系 Markdown 的方式，但有一些選項並不會一併產生，例如 Header、Footer、Sidebar 的文字

這邊需要透過以下指令來產生

```bash
# 產生翻譯 JSON 檔
npm run write-translations -- --locale zh-tw
```

```markdown
# 在 docusaurus-plugin-content-docs-demo 資料夾內會自動產生每個版本的翻譯檔

website
└── i18n
    └── zh-tw
        ├── docusaurus-plugin-content-docs-demo
        │   ├── current
        │   ├── version-2.0.0
        │   ├── version-1.0.0
        │   ├── current.json                        # demo 資料庫 zh-tw 版本的翻譯檔
        │   ├── version-2.0.0.json                  # demo 資料庫 zh-tw 版本的翻譯檔（2.0.0）
        │   └── version-1.0.0.json                  # demo 資料庫 zh-tw 版本的翻譯檔（1.0.0）
        └── docusaurus-plugin-content-docs-tutorial
            ├── current
            ├── version-2.0.0
            ├── version-1.0.0
            ├── current.json                        # tutorial 資料庫 zh-tw 版本的翻譯檔
            ├── version-2.0.0.json                  # tutorial 資料庫 zh-tw 版本的翻譯檔（2.0.0）
            └── version-1.0.0.json                  # tutorial 資料庫 zh-tw 版本的翻譯檔（1.0.0）
```
