## What's EdgeLink

EdgeLink is an intelligent gateway software designed to connect with over 200 types of devices and controllers. It enables integration with PLCs, inverters, and various sensors, supporting multiple industrial protocols. With its lightweight architecture and flexible deployment options, EdgeLink empowers users to quickly build industrial IoT applications and realize seamless data connectivity from edge devices to the cloud.

## Features

- Lightweight software solution for collecting data from the edge to the cloud.
- Supports various industrial protocols (e.g., PLC, CNC, Inverter, SCADA, DCS).
- Centralized management for device configuration and monitoring.
- Flexible data mapping and tag management.
- Real-time data acquisition and logging.
- Supports custom driver development and plugin integration.
- Containerized deployment for easy scaling and integration.
- Multiple security mechanisms for data transmission and device management.
- Provides RESTful API for third-party system integration.
